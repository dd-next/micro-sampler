micro sampler — guide

quick start

  1. Hold REC and hold a key 1–16 — the mic records for as long as you hold it. Slots 1–8 are melodic, 9–16 are drum.
  2. Release. The sound is assigned and you are back in KEYS. Play it: melodic keys are a chromatic scale, drum keys are 16 slices.
  3. Hit PLAY, hold WRITE and punch keys in time — notes quantize to the grid.
  4. Hold FX and hold a key for a punch-in effect.

modes

KEYS
Default. Plays the selected sound.
SOUND
+ key selects one of 16 sounds.
PATTERN
+ key selects a pattern. Hold and press several keys to build a chain (up to 128). Press copy in this mode, then a key, to duplicate the pattern into that key's slot.
WRITE
Stopped: keys are the 16 steps, tap to toggle. Playing: keys punch in, quantized. Hold WRITE and turn a knob to lock that parameter to the current step.
FX
+ key applies a punch-in effect while held. With WRITE also active, the effect is saved into the pattern.
REC
+ key records into that slot for as long as it is held.
BPM
Keys 1–16 set master volume.

Tap a mode button to latch it, or hold it down as a modifier — both work, on touch and mouse alike.
